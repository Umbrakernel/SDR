## О проекте

Репозиторий содержит лабораторные работы по изучению SDR-приёмопередатчика **ADALM-Pluto**. В проекте рассматриваются приём FM-сигнала в GNU Radio, управление Pluto через SoapySDR, сохранение комплексных отсчётов в PCM-файл и анализ принятых сигналов во временной и частотной областях.

Основная программа находится в `src/main.c` и поддерживает два режима:

- `rx` — приём сигнала и запись I/Q-отсчётов в `rxdata.pcm`;
- `tx` — формирование двухтонового сигнала и его передача с использованием временных меток RX.

Python-скрипты для построения графиков расположены в папке `scripts/`, а отчёты по лабораторным работам — в `reports/`.

## Используемые технологии

- **ADALM-Pluto** — SDR-приёмопередатчик на базе AD9363.
- **SoapySDR** — программный интерфейс для управления приёмом и передачей.
- **SoapyPlutoSDR** — драйвер для подключения Pluto к SoapySDR.
- **libiio / libad9361-iio** — библиотеки для взаимодействия с устройством.
- **C** — реализация потоков приёма и передачи.
- **Python, NumPy, Matplotlib** — чтение PCM и визуализация сигналов.
- **GNU Radio Companion** — создание блок-схемы FM-приёмника.
- **CMake** — сборка программы.

## Параметры основной программы

В текущей версии `src/main.c` заданы следующие параметры:

| Параметр | Значение |
|---|---:|
| Центральная частота RX/TX | 800 МГц |
| Частота дискретизации | 1 МГц |
| Формат отсчётов | CS16 (`int16`, I и Q) |
| Усиление RX | 30 |
| Усиление TX | 40 |
| Задержка TX относительно RX timestamp | 4 мс |

### Формируемый сигнал в режиме TX

Сигнал повторяется циклически и состоит из трёх участков:

| Участок | Длительность | Частота | Амплитуда |
|---|---:|---:|---:|
| Первый тон | 2 мс | 5 кГц | 8192 |
| Второй тон | 2 мс | 10 кГц | 4096 |
| Пауза | 300 мс | — | 0 |

Полный период составляет **304 мс**. I- и Q-компоненты формируются как косинус и синус соответственно. Амплитуда второго участка в два раза меньше амплитуды первого.

## Сборка

Сборка выполняется из корневой папки проекта с помощью CMake:

```bash
cmake -S . -B build
cmake --build build -j2
```

Необходимые системные библиотеки и настройки окружения описаны в [BUILD.md](BUILD.md), если этот файл присутствует в репозитории.

Python-зависимости устанавливаются отдельно:

```bash
pip install -r requirements.txt
```

## Запуск программы

Команды выполняются из корневой папки репозитория. Вместо `USB_URI` укажи URI нужной платы.

### Режим приёма — RX

```bash
./build/sdr rx USB_URI
```

В этом режиме программа:

1. Настраивает приём на 800 МГц с частотой дискретизации 1 МГц.
2. Устанавливает RX gain 30.
3. Создаёт и запускает поток RX.
4. Пропускает первые 128 буферов для прогрева.
5. Проверяет временные метки принятых блоков.
6. Записывает комплексные отсчёты в `rxdata.pcm` в текущей папке.

При повторном запуске `rxdata.pcm` перезаписывается.

### Режим передачи — TX

```bash
./build/sdr tx USB_URI
```

В режиме TX программа запускает **оба потока — RX и TX**. По временной метке принятого RX-блока рассчитывается время передачи: к ней добавляется задержка 4 мс. Если блок передаётся частями, временная метка каждой следующей части сдвигается с учётом уже переданных отсчётов.

Передача выполняется циклически: 2 мс тона 5 кГц, 2 мс тона 10 кГц и 300 мс паузы.

> Важно: режим TX использует RX-поток того же экземпляра устройства для получения временных меток. Для приёма передаваемого сигнала на второй плате отдельно запусти режим `rx`, указав URI принимающего устройства.

Остановка программы в обоих режимах — `Ctrl+C`.

## Анализ принятых данных

В режиме RX создаётся `rxdata.pcm` в текущей рабочей директории. Комплексные отсчёты записываются последовательно:

```text
I0, Q0, I1, Q1, I2, Q2, ...
```

Каждая компонента имеет тип `int16`.

### График I/Q

```bash
python3 scripts/plot.py rxdata.pcm --start 37063000 --count 8000
```

Скрипт отображает I- и Q-компоненты выбранного участка записи. Для сохранения графика:

```bash
python3 scripts/plot.py rxdata.pcm --save reports/iq.png
```

### Спектр сигнала

```bash
python3 scripts/spectrum.py rxdata.pcm
```

Скрипт строит спектры двух участков записи. В нём используются фиксированные начальные позиции отсчётов, поэтому для другого PCM-файла эти позиции могут потребовать изменения.

Для сохранения графика:

```bash
python3 scripts/spectrum.py rxdata.pcm --save reports/spectrum.png
```
